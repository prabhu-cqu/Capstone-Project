# SmartShop AI - Capstone Project

SmartShop AI is an AI-enhanced e-commerce web application developed for a fictional small Australian retailer selling computer, mobile and study accessories to students and young professionals.

The project combines standard e-commerce functionality with controlled AI capabilities to help customers search, understand and compare suitable products.

## Main Features

- Product catalogue
- Search, filter and sort products
- Product details
- Customer accounts
- Shopping cart
- Simulated checkout
- Order history
- AI shopping assistant
- Guided product recommendations
- Customer review summaries
- Administrative product, stock and order management

## Project Documentation

Detailed project documentation is organised within this repository:

- `docs/project-proposal.md` - Project proposal and overall project planning
- `docs/requirements/` - Project requirements and progress tracking
- `ai/evaluation/` - AI evaluation planning and evidence
- `tests/` - Testing plans, test cases and results

## Project Scope

The project focuses on developing a functional academic prototype. Real payment processing, delivery-provider integration, large-scale hosting, demand forecasting and long-term behavioural profiling are outside the current project scope.
