# SmartShop AI - AI Evaluation Plan

## Purpose

This document outlines how the AI features of SmartShop AI will be evaluated during development and testing.

## AI Features to Evaluate

The project currently plans to evaluate three main AI capabilities:

1. Catalogue-based shopping assistant
2. Guided product recommendations
3. Customer review summaries

## Evaluation Areas

| Evaluation Area | What Will Be Checked | Status |
|---|---|---|
| Catalogue Grounding | AI responses should use products available in the SmartShop catalogue | Planned |
| Recommendation Relevance | Recommended products should match the user's stated needs | Planned |
| Product Accuracy | Product information should match stored catalogue information | Planned |
| Response Time | AI responses should be returned within the agreed project target | Planned |
| Unsupported Claims | AI should not provide unsupported price, stock or product information | Planned |
| Fallback Behaviour | The system should provide a controlled response when the AI service is unavailable | Planned |

## Planned Testing Approach

AI test cases will be developed as the SmartShop AI features are implemented. Test inputs and expected outcomes will be recorded so that AI responses can be evaluated consistently.

Actual test results and identified issues will be added during the implementation and testing stages.
